# Лабораторная работа 4 — «Космический корабль «Аврора»

## Назначение

Консольная игра на Python 3, в которой игрок пытается выбраться с космического корабля: найти инструмент, починить реактор и запустить спасательную капсулу. Вся логика построена на if/else в одном файле main.py.

## Состав проекта

- main.py — запуск игры, обработка команд и игровой цикл.
- requirements.txt — список сторонних зависимостей проекта.
- docs/lab2.docx — отчёт по лабораторной работе 2.

## Команды

    help                  — список команд
    look                  — описание текущей комнаты
    go <направление>      — куда идти
    take tool             — взять инструмент
    use tool              — использовать инструмент
    use capsule           — использовать капсулу
    energy                — узнать оставшуюся энергию
    exit                  — выйти из игры

Доступные направления: `bridge`, `mess`, `reactor`, `cargo`, `airlock`, `capsule`.

Команды вводятся точной строкой, как в списке. Если команда или действие некорректны, программа сообщает об этом и продолжает работу.

## Устройство программы

В main.py глобальные переменные хранят энергию, состояние реактора, текущую комнату и наличие инструмента. Энергия изначально равна 100, реактор не починен, инструмента нет, текущая комната пустая. Игровой цикл while True читает команду и через if/else меняет состояние игры.

При переходе между комнатами энергия обычно уменьшается на 5. Переход в реактор из кают энергию не тратит. Если энергия равна 0, игра завершается поражением. Инструмент подбирается в грузовом отсеке командой `take tool`, а используется в реакторе командой `use tool`. Реактор считается починенным только при наличии инструмента. Капсула запускается командой `use capsule`, если игрок находится у капсулы, реактор починен и энергия больше нуля.

Внешние библиотеки не требуются.

## Запуск

Откройте проект в PyCharm и запустите main.py.

Пример маршрута к победе: `go bridge` → `go cargo` → `take tool` → `go bridge` → `go mess` → `go reactor` → `use tool` → `go mess` → `go bridge` → `go cargo` → `go airlock` → `go capsule` → `use capsule`.
